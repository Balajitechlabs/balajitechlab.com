# 🔐 Secure Password Generator

A lightweight, sleek, and responsive client-side password generator built with **HTML5**, **CSS3**, and **modern JavaScript**.

### ✨ Highlights & Features
- 🎲 **Customizable Complexity**: Toggle uppercase, lowercase, numbers, and special symbols.
- 📏 **Adjustable Length**: Generate passwords from 8 up to 64 characters with live entropy strength calculation.
- 📋 **One-Click Copy**: Instant clipboard copy action with animated feedback.
- 🔒 **100% Client-Side**: Operates entirely in your browser with zero network requests for complete privacy.
