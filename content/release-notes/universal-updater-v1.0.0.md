# ⚡ Universal Updater for Raycast

**Universal Updater** is a fast, native Raycast extension for macOS to check, upgrade, audit, and backup packages across all popular package ecosystems from one unified command palette.

### 📦 Supported Package Managers
- 🍺 **Homebrew** (Formulae & Casks)
- 📦 **Node.js** (`npm`, `pnpm`, `yarn`, `bun`)
- 🦀 **Rust** (`cargo`)
- 🐍 **Python** (`pip`, `pipx`)
- 💎 **Ruby** (`gem`)
- 🍏 **Mac App Store** (`mas-cli`)
- ⚡ **Deno**, **Composer**, and **Go Tools**

### ✨ Features
- 🔍 **One-Click Multi-Manager Scan**: Scans all installed package managers simultaneously.
- ⚡ **Selective & Bulk Upgrades**: Update individual packages or batch-upgrade everything.
- 🛡️ **Package Auditing**: Instant vulnerability checks and outdated dependency reports.
- 💾 **System Backup & Restore**: Snapshot and restore your entire developer toolchain.
