## QuickDash v5.0.0 Official Release

### Available Download Formats
- **`app-universal-release.apk`**: Recommended universal build. Works on 100% of Android devices (Android 7.0–15).
- **`app-arm64-v8a-release.apk`**: Optimized 64-bit ARM build (~25 MB) for modern devices (Pixel 6/7/8/9, Galaxy S20+, OnePlus 8+).
- **`app-armeabi-v7a-release.apk`**: 32-bit ARM build (~20 MB) for legacy hardware.
- **`app-release.aab`**: Official Google Play App Bundle format for Play Console publishing.

### Installation Guide
1. Download your preferred APK format above.
2. On your Android phone, enable **Settings → Install unknown apps** for your browser or file manager.
3. Open the downloaded file and tap **Install**.

> 🛡️ **Play Protect Note:** If Google Play Protect shows a prompt, tap **"More details"** → **"Install anyway"**. QuickDash is 100% telemetry-free and open source.
