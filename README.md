## 🌟 Overview

**[balajitechlab.com](https://balajitechlab.com)** is a modern, high-performance developer portfolio built with Next.js 16 (Turbopack), React 19, and hardware-accelerated WebGL shaders. It showcases flagship applications like **QuickDash**, **Universal Updater**, and **Luxora OS**, combined with interactive developer features and low-latency micro-interactions.

---

## ✨ Features & Architecture

* **🎨 3 Live WebGL GPU Shader Themes**:
  * **Theme 1: AMOLED Topographic**: Damascus-style topographic contour isolines with pitch-black AMOLED shutoff.
  * **Theme 2: The Universe Within**: 3D neural constellation shader with live color modulation.
  * **Theme 3: Voronoi Distances**: Inigo Quilez Euclidean crystal distance isolines.
* **⌨️ Raycast & Vercel Spotlight Command Palette (`cmdk`)**:
  * Instant access via **`Cmd + K`** (Mac), **`Ctrl + K`** (Windows), or `/`.
  * Live shader theme switcher, section navigation, resume viewer, and instant clipboard actions.
* **🌊 Lenis 120 FPS Momentum Scrolling (`lenis`)**: Butter-smooth inertial scrolling optimized for trackpads and mouse wheels.
* **💎 3D Holographic Parallax Tilt**: Hardware-accelerated 3D perspective rotation with dynamic specular glare on all project cards.
* **🔊 Synthesized Web Audio Haptics (`soundFx.ts`)**: Pure browser Web Audio API generating crisp, mechanical clicks, bubble pops, and celebratory victory chords.
* **🚀 Instant Telegram Bot Contact Form**: Real-time serverless webhook dispatching formatted contact messages directly to Telegram with HTML parsing.
* **🦶 Raycast-Structured Footer**: Multi-column responsive matrix featuring Material 3 Expressive social pill chips, live Asia/Kolkata IST clock, and brand logo.
* **📱 100% Mobile & Apple Silicon Economy**: Fully responsive layout adhering strictly to 8GB RAM machine limits and 0 layout shifts.

## 🚀 Getting Started

### Prerequisites
* **Node.js**: `v20+`
* **Package Manager**: `pnpm` (recommended)

### Installation

```bash
# Clone repository
git clone https://github.com/balajitechlabs/balajitechlab.com.git
cd balajitechlab.com

# Install dependencies
pnpm install

# Configure environment variables
cp .env.example .env.local
```

### Environment Configuration (`.env.local`)

```env
GITHUB_TOKEN=your_github_personal_access_token
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHAT_ID=your_numeric_chat_id
```

### Running Locally

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
